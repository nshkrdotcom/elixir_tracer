## [0.1.0] - 2025-10-17

### Added

- Initial release of ElixirTracer
- Local-first observability framework for Elixir applications
- New Relic API parity for drop-in compatibility
- In-memory storage backend for trace data
- Core tracing functionality:
  - Transaction tracking
  - Custom event recording
  - Error tracking
  - Custom metrics
- Zero-configuration setup with sensible defaults
- Privacy-focused architecture (all data stays local)
- Minimal performance overhead
- Basic documentation and examples
